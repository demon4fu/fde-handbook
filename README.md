## 使用方式

先读方法与边界，再将案例、工作表和验收标准带入实际项目。示例代码及测试记录只构成书中说明的适用范围；真实部署仍需结合权限、数据、成本和组织环境重新评审。

## 编译

解压源包，以根目录 `main.tex` 为主文件，使用 XeLaTeX。字体、许可证、实际使用的图片及章节文件随包提供，详见源包内 `README.md`。已验证两轮干净构建；在线平台的时间与资源限制可能影响编译。
